# Paquete de entrega

El ZIP de esta carpeta se genera con todos los archivos versionables del proyecto y excluye `.git/`, `build/` y las salidas temporales de Compute Sanitizer.

Antes de entregar, agregue los carnés de los integrantes si la guía UVG los exige y exporte `docs/INFORME_BORRADOR.md` a PDF.
